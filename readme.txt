Create structured learning content with modules and a flexible hierarchy of lessons, sub-lessons and topics.

== Description ==

Learning Resources provides a hierarchical Learning Resources content type and a Modules taxonomy for organising curriculum content.

Every resource can have a parent and children. Resource metadata includes type, estimated duration, difficulty and learning objectives, ready for future editor and front-end learning tools.

== Installation ==

1. Upload the plugin folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the Plugins menu in WordPress.
3. Open Learning Resources to create and organise content.

== Frequently Asked Questions ==

= Can a lesson contain sub-lessons? =

Yes. Learning Resources supports parent/child nesting.

= Are modules the same as parent resources? =

No. Modules classify resources. The parent/child relationship defines the learning structure.
